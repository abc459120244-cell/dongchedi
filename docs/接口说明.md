# 接口说明

所有接口统一以 `/api` 开头，返回 JSON（UTF-8）。出错时返回统一结构：

```json
{
  "status": 404,
  "error": "Not Found",
  "message": "车型不存在: 9999",
  "details": [],
  "path": "/api/cars/9999",
  "timestamp": "2026-10-09T10:31:02.412"
}
```

## 2. 车型筛选

### GET /api/cars

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | 否 | 关键字，匹配车型名、品牌、标签、卖点，支持空格分词 |
| `brand` | string[] | 否 | 品牌，多值（可重复传参或使用英文逗号分隔） |
| `level` | string[] | 否 | 级别：`MINI` `SMALL` `COMPACT` `MID` `LARGE` `FULL` |
| `bodyType` | string[] | 否 | 车身：`SEDAN` `HATCHBACK` `SUV` `MPV` `COUPE` `SPORTS` `PICKUP` `WAGON` |
| `energyType` | string[] | 否 | 能源：`GASOLINE` `DIESEL` `HEV` `PHEV` `EREV` `BEV` |
| `scene` | string[] | 否 | 场景：`FAMILY` `COMMUTE` `FIRST_CAR` `FAMILY_TRIP` `LONG_TRIP` `BUSINESS` `PERFORMANCE` `OUTDOOR` `RIDE_HAILING` |
| `minPrice` / `maxPrice` | number | 否 | 价格区间（万元） |
| `minSeats` | int | 否 | 最少座位数 |
| `minRange` | int | 否 | 纯电续航下限（km） |
| `maxFuel` | number | 否 | 百公里油耗上限（L） |
| `minScore` | number | 否 | 用户评分下限（0~5） |
| `maxAcceleration` | number | 否 | 零百加速上限（秒），例如 `4` 表示只要 4 秒内的性能车 |
| `sort` | string | 否 | `SALES_DESC`（默认）`PRICE_ASC` `PRICE_DESC` `SCORE_DESC` `POWER_DESC` `RANGE_DESC` `ACCELERATION_ASC` `ID_ASC` |
| `page` / `size` | int | 否 | 页码（从 1 开始，默认 1）、每页条数（默认 12，上限 60） |

无法识别的枚举取值会被忽略并打印 warn 日志，不会让接口返回 400。

```bash
curl "http://localhost:8080/api/cars?energyType=BEV&energyType=EREV&minPrice=15&maxPrice=30&sort=PRICE_ASC&page=1&size=5"

# 只要零百 4 秒内的性能车，并按加速从快到慢排序
curl "http://localhost:8080/api/cars?maxAcceleration=4&sort=ACCELERATION_ASC"
```

### GET /api/cars/{id}

返回单个车型，不存在时返回 404 与统一错误结构。

### GET /api/cars/filters

返回前端筛选面板所需的选项，并附带每个选项下的车型数量（`count`）。

### GET /api/cars/compare

```bash
curl "http://localhost:8080/api/cars/compare?ids=1,3,9"
```

返回顺序与传入顺序一致；数量少于 2 或多于 4 时返回 400，包含不存在的车型时返回 404。

## 3. 智能推荐

### POST /api/recommend

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `minPrice` / `maxPrice` | number | 10 / 20 | 预算区间（万元） |
| `scenes` | string[] | `[]` | 用车场景，取值同筛选接口的 `scene` |
| `energyPreference` | string | `ANY` | `ANY` `NEW_ENERGY` `TRADITIONAL` |
| `minSeats` | int | 5 | 座位数需求（2~9） |
| `priority` | string | `COMPREHENSIVE` | `COMPREHENSIVE` `ECONOMY` `PERFORMANCE` `SPACE` `REPUTATION` |
| `limit` | int | 5 | 返回条数（1~20，同时受 `dongchedi.recommend.max-limit` 限制） |

```bash
curl -X POST http://localhost:8080/api/recommend \
  -H "Content-Type: application/json" \
  -d '{"minPrice":15,"maxPrice":20,"scenes":["FAMILY","COMMUTE"],"energyPreference":"NEW_ENERGY","minSeats":5,"priority":"ECONOMY","limit":3}'
```

### GET /api/recommend

与 POST 等价的快速版本，参数同名，用查询参数传递；`scenes` 可重复传参。

```bash
curl "http://localhost:8080/api/recommend?minPrice=15&maxPrice=20&scenes=FAMILY&limit=3"
```

### GET /api/recommend/options

返回场景、优先级、能源偏好选项与常用预算档位，前端表单直接使用该接口渲染。

### GET /api/statistics/car-ranking

车型销量排行榜，按车型月销量降序。排名徽标、销量条形图与占比由前端渲染。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `limit` | 10 | 返回条数，1~50 |
| `scope` | `ALL` | `ALL` 全部、`NEW_ENERGY` 新能源、`TRADITIONAL` 燃油/油混、`PERFORMANCE` 零百 5 秒内性能车 |
| `brand` | 空 | 可选，限定品牌，例如 `比亚迪` |
| `bodyType` | 空 | 可选，限定车身形式，例如 `SUV` |

## 6. 认证接口

登录成功后服务端会创建会话，浏览器自动携带 `JSESSIONID` Cookie。
需要登录的接口若未登录，统一返回 401：

```json
{ "status": 401, "error": "Unauthorized", "message": "请先登录后再操作", "details": [], "path": "/api/favorites" }
```

### POST /api/auth/register

```bash
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"xiaowang01","password":"wang12345","nickname":"小王"}'
```

状态码 `201`，返回注册后的用户信息，并且**已经处于登录状态**：

```json
{
  "id": 3,
  "username": "xiaowang01",
  "nickname": "小王",
  "displayName": "小王",
  "role": "USER",
  "roleLabel": "普通用户",
  "createdAt": "2026-10-10T16:52:31.204"
}
```

校验规则：用户名 4~20 位字母 / 数字 / 下划线；密码 6~32 位且同时包含字母和数字；
用户名重复返回 `409`，参数不合法返回 `400`。

### POST /api/auth/login

```bash
curl -c cookie.txt -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"demo","password":"demo123"}'
```

成功返回用户信息；用户名或密码错误返回 `401`；连续失败 5 次返回 `429`（锁定 5 分钟）。

### POST /api/auth/logout

```json
{ "message": "已退出登录" }
```

幂等：未登录时调用同样返回成功。

### GET /api/auth/me

返回当前登录用户；未登录返回 `401`。前端启动时用它判断登录态。

## 7. 收藏接口（需登录）

### GET /api/favorites

返回当前用户收藏的完整车型信息，按收藏顺序排列。

### GET /api/favorites/ids

```json
[1, 6, 16]
```

### POST /api/favorites/{carId} 与 DELETE /api/favorites/{carId}

```bash
curl -b cookie.txt -X POST http://localhost:8080/api/favorites/35
```

```json
{ "favorited": true, "total": 4, "ids": [1, 6, 16, 35] }
```

收藏不存在的车型返回 `404`；单个用户收藏上限 50 款，超出返回 `400`。

### DELETE /api/favorites

清空当前用户的收藏，返回 `{ "favorited": false, "total": 0, "ids": [] }`。
