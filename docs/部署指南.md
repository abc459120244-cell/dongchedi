# 部署指南（云服务器 + 数据库 + 外网访问）

本项目有两种部署方式，任选一种即可满足「部署到服务器 + 不同网络可访问」的验收要求：

| 方式 | 适用场景 | 数据库 |
| --- | --- | --- |
| 方式一：Docker Compose（推荐） | 服务器已装 Docker，想一键起 MySQL + 应用 + Nginx | MySQL 8（容器内） |
| 方式二：直接运行 jar + 系统 MySQL | 服务器已有 MySQL，或用宝塔面板 | MySQL 8（本机） |

---

## 一、准备工作

1. 一台**有公网 IP** 的云服务器（阿里云 / 腾讯云 / 华为云均可），建议 2 核 4G、Ubuntu 22.04。
2. 安全组 / 防火墙放行端口：`80`（Nginx）、`443`（HTTPS，可选）、`8080`（直接访问应用时）。
3. 代码已经推送到远程仓库（Gitee / GitHub）。

登录服务器并拉取代码：

```bash
sudo apt update && sudo apt install -y git curl
git clone <你的仓库地址> dongchedi
cd dongchedi
```

## 二、方式一：Docker Compose 一键部署

```bash
# 1. 一键安装 Docker 并启动（已装则自动跳过）
sudo bash deploy/deploy-ubuntu.sh

# 或者手动分步执行：
curl -fsSL https://get.docker.com | sh
sudo docker compose -f deploy/docker-compose.yml up -d --build
```

启动完成后：

```bash
sudo docker compose -f deploy/docker-compose.yml ps     # 查看三个容器状态
curl http://localhost/api/system/health                 # 应返回 {"status":"UP",...}
```

浏览器访问 `http://服务器公网IP/` 即可打开买家端，`http://服务器公网IP/merchant.html` 打开商家端。

> 容器结构：`nginx`（80 端口对外）→ `app`（Spring Boot，8080 内网）→ `mysql`（3306 内网，数据落在 `mysql-data` 卷）。
> 数据库密码在 `deploy/docker-compose.yml` 里，正式环境请修改后再上线。

## 三、方式二：jar + 本机 MySQL

### 1. 安装 JDK 与 MySQL

```bash
sudo apt install -y openjdk-21-jre-headless mysql-server
sudo mysql_secure_installation          # 按提示设置 root 密码
```

### 2. 创建数据库与账号

```sql
CREATE DATABASE dongchedi DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'dongchedi'@'%' IDENTIFIED BY 'change-me';
GRANT ALL PRIVILEGES ON dongchedi.* TO 'dongchedi'@'%';
FLUSH PRIVILEGES;
```

### 3. 打包并上传

本地执行：

```bash
mvn clean package -DskipTests
scp target/dongchedi.jar root@服务器IP:/opt/dongchedi/
```

### 4. 用 systemd 托管（开机自启 + 崩溃自动重启）

```bash
sudo mkdir -p /opt/dongchedi
sudo useradd -r -s /sbin/nologin appuser || true
sudo cp deploy/dongchedi.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now dongchedi
sudo systemctl status dongchedi
```

数据库连接信息在 `deploy/dongchedi.service` 的 `Environment=` 中修改（`DB_HOST` / `DB_USER` / `DB_PASSWORD`）。

### 5. 配置 Nginx（80 端口对外，并支持 SSE 实时消息）

```bash
sudo apt install -y nginx
sudo cp deploy/nginx.conf /etc/nginx/conf.d/dongchedi.conf
sudo nginx -t && sudo systemctl reload nginx
```

> 直接在 `deploy/nginx.conf` 里把 `app:8080` 换成 `127.0.0.1:8080` 即可（因为不再是 Docker 网络）。

## 四、验证清单（对应验收标准）

| 验收点 | 验证方式 |
| --- | --- |
| 不同网络可访问 | 用手机 4G/5G（关掉 WiFi）打开 `http://服务器IP/`，能正常打开说明外网可达 |
| 前后端数据库打通 | 商家端新增一个车源 → 刷新买家端列表能看到；重启应用后数据仍在（说明落库了） |
| 多端互动 | 电脑打开买家端，手机打开商家端：买家下单 → 商家端**无需刷新**即弹出「收到新的订单」 |
| 数据落库可核查 | `docker compose exec mysql mysql -uroot -p dongchedi -e "select id,name,brand,price from car limit 5; select id,car_name,status from car_order;"` |

## 五、没有公网服务器时的备选方案

如果暂时没有云服务器，可以用内网穿透把本机服务暴露到公网（仅用于演示，稳定性和带宽有限）：

| 工具 | 说明 |
| --- | --- |
| cpolar / natapp / 花生壳 | 注册后下载客户端，映射本地 `8080` 端口，得到一个公网域名 |
| frp | 需要另有一台公网服务器作为服务端 |

例如 cpolar：

```bash
cpolar http 8080        # 得到形如 https://xxxx.cpolar.cn 的公网地址
```

拿到公网地址后，让老师用手机流量访问即可证明「不同网络可访问」。

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 访问 IP 打不开 | 安全组/防火墙没放行 80；或 Nginx 未启动：`systemctl status nginx` |
| 页面能开但数据是空的 | 数据库未初始化：应用启动时会自动建表并导入 `cars.json` 的 63 款车型，检查日志中的 `DataSeeder` 输出 |
| 商家端收不到实时消息 | Nginx 必须对 `/api/notifications/stream` 关闭 `proxy_buffering`（本项目 `nginx.conf` 已配置） |
| 端口 8080 被占用 | 用 `--server.port=18080` 换端口启动，或在 Nginx 里改代理端口 |
| 中文乱码 | 启动时加 `-Dfile.encoding=UTF-8`；MySQL 建库使用 `utf8mb4` |
| H2 控制台进不去 | 默认地址 `/h2-console`，JDBC URL `jdbc:h2:file:./data/dongchedi`，用户名 `sa`，密码为空（仅开发环境） |
