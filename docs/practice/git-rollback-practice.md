# 版本回滚练习记录（practice/rollback-demo 分支）

本分支用于演示第二种回滚方式：`git reset --hard`（直接移动分支指针，丢弃提交）。

练习步骤：

1. 在干净的工作区上创建一个临时提交，模拟「已经写错并提交」的状态。
2. 用 `git reset --hard HEAD~1` 把分支指针退回上一个正确提交。
3. 用 `git reflog` 确认被丢弃的提交仍然可以被找回。

> 与 `git revert` 的区别：`reset` 会改写分支历史，适合**尚未推送**的本地提交；
> `revert` 会新增一个反向提交，适合**已经推送到远程**的提交。
